## Description

A deck can be rendered to PDF, with or without its collected results, as a self-contained file.

## Updates

- 2026-08-13 — GET /api/presentations/:id/deck.pdf ships both readings — ?results=true (default) renders each slide's tally under it, ?results=false the deck alone — authorized as an edit for both, like the REQ095 workbook. server/deck-pdf.ts is a pure document model + a pdf-lib flow that breaks it onto pages, and the results half re-lays out aggregateRowsFor() rather than computing a second tally. Presenter surface now opens an ExportDialog over one descriptor of all three formats; SLIDE_TYPE_LABELS moved to server/schemas.ts so both sides name a slide type once. Font coverage beyond Latin-1 is folded and filed as REQ158.
- 2026-08-14 — The wrap path this export renders through was quadratic in the length of a single unbroken text run, and the slide fields feeding it were uncapped — one request could block the event loop for minutes. Fixed and tracked as REQ159; the rendered output for ordinary decks is unchanged.
- 2026-08-14 — Review fixes: the quiz branches of questionBlocksFor read the time limit through quizTimeLimitFor — a no-countdown question (authored 0, or a negative stored value) prints 'No time limit — every correct answer scores the same.' instead of 'Time limit: 0 seconds.'; and the points-slide rule interpolates POINTS_BUDGET instead of a literal 100.
