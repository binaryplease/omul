## Description

As an author, I want to edit a slide's body text directly on the slide in the editor, in the same place I edit its question, so that I do not leave the slide to change the words on it.

Done when the editor canvas offers the body text of a slide that has one as an editable field, with the same stored value and length cap as today's field, and the change shows at once on the canvas and in the rail.

## Notes

**Current behaviour.** The canvas offers the question as a textbox named "Slide question". The body is edited only through the textarea in the settings column (`src/components/SlideEditor.tsx`, `onUpdate({ body: … })`), capped at `SLIDE_TEXT_MAX_LENGTH`.

**Where it comes from.** A note in the 2026-11-03 acceptance run, on the step that exports a deck with a body text to PDF. The step itself passed; this is a separate request.

**Related.** Editing ranking items directly on the slide is the same request for another field, and it is listed with the editor-layout follow-up of the first acceptance run. No requirement exists for that one yet.

**Numbering.** This catalog skips REQ214 to REQ244 because those numbers are taken by work not yet published, so this requirement takes REQ245.
