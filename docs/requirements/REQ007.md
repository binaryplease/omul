## Description

A generation call turns a short text prompt into a draft deck — slide types and question text chosen by the generator — and returns it as an ordinary editable deck. The output is a draft: nothing downstream treats generated content as verified.

## Updates

- 2026-08-14 — Generation path shipped end to end: POST /api/deck-generation turns a short prompt into a draft deck and returns it as an ordinary editable presentation (same createPresentation path, same one-time creatorToken, nothing recording the origin). server/deck-generator.ts is its own module (ADR-0032) over the Vercel AI SDK + @ai-sdk/google, off unless GOOGLE_GENERATIVE_AI_API_KEY is set and reached by a dynamic import so nothing else loads a provider. The draft rule is enforced by the vocabulary rather than by stripping: the generated-slide schema has no isCorrect/quizAnswers/guessReference/pinArea, so no generated deck ever asserts a correct answer and marking the key is the organizer's first edit. Ten slide types, 3-12 slides, 500-char prompt; unusable slides dropped individually, over-long text refused via slideWriteRefusalFor. GET /api/deck-generation reports availability so the control is drawn disabled with its reason (ADR-0025). Own rate-limit budget (5 per 5 min) that also spends the create budget. Client: /generate page, HomePage entry, api.generatePresentation. 66 new tests (schemas + integration over a stub — no key, no network); ADR-0016 exception documented in AGENTS.md, README and docs/deployment.md.
