## Description

As an organizer who builds a quiz with a screen reader, I want the time-limit field in a quiz slide's settings to announce what it sets when it takes focus, so that I can set a question's countdown without guessing what an unnamed number box is for.

The quiz question's countdown (REQ057), set in the slide's settings column (REQ155), opens from its "Time limit" row into a number box under the caption "Time limit (seconds)". The caption is drawn but not bound to the box, so assistive technology announces a spin button with no name (WCAG 2.2 SC 4.1.2 Name, Role, Value; SC 1.3.1 Info and Relationships). This repairs REQ057's editor surface.

- **The number box's accessible name** is "Time limit (seconds)", the caption's own words, held in one constant so the visible and the announced name cannot drift apart.
- **Built like the editor's other named inputs:** the name sits on the control as `aria-label`. The shared `Field` caption deliberately heads its control rather than binding to it, and is not changed here.
- **Unchanged:** the field's value handling, range (0–300), the "Time limit" row that opens it, and every other field in the editor.

## Notes

Defect, **internal**: found by a re-test of the quiz fix chain, which read the field as a nameless `spinbutton` in an accessibility snapshot and found no label, `aria-label` or `aria-labelledby` on it.

Out of scope: an accessibility sweep of the rest of the editor. Several other number boxes under a `Field` caption (axis and range bounds, a guess question's correct number and tolerance) share the same unbound caption; they are not repaired by this requirement.

As shipped (2026-10-31):

- **Client:** `QuizTimeLimitField` in `src/components/SlideEditor.tsx` is the number box and its caption, lifted out of `ScoringGroup` unchanged except for `aria-label={QUIZ_TIME_LIMIT_LABEL}`; `ScoringGroup` composes it inside its `DisclosureRow`.
- **Server, participant view, `cli/`:** not touched.
- **Tests:** `src/components/SlideEditor.test.ts` renders the field and asserts the input's accessible name — read by `aria-labelledby`, `aria-label` or `<label for>`, in that order — equals the caption's text, at 30 seconds and with the countdown off. Both fail on the tree before this change.
