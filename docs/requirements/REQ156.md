## Description

Presenter notes are authored in a strip directly beneath the canvas (REQ152) — collapsed to a single readable line of the note's text with a visible "only you" privacy marker, expanding in place to the full text editor — rather than inside the settings column. An empty strip invites in the same position ("Add presenter notes…"), so the affordance does not disappear with its content.

## Notes

Placement is the point: notes are written in the same pass as the slide's words and read while presenting it, so they belong with the slide, not filed under settings — and every adjacent slide tool keeps them exactly there, which makes this the position an author's hand already knows.

What keeps notes private is the wire, not this strip: the server empties the field for every caller that cannot edit the deck (REQ090). The "only you" marker states that existing fact at the point of authoring; nothing about the transport changes here.
