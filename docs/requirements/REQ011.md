## Description

Multiple-choice results can be read as absolute counts or as shares of the respondents. The choice is display state and does not change the stored votes.

## Updates

- 2026-07-28 — Choice results now read as counts, percentages or both. New slide setting mcValueDisplay (default 'both' — what every existing deck already rendered) is the authored default; the presenter switches it live on the shared screen with a segmented control sitting next to the results (ADR-0031). The live switch is browser-local and never written back to the deck, so adapting to the room does not re-author the presentation. One shared descriptor (MC_VALUE_DISPLAY_OPTIONS) and one formatter serve the editor, the presenter and all four visualizations.
