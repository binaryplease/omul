## Description

A catalog of prebuilt decks can be listed and filtered, and any entry copied into a new editable deck.

## Updates

- 2026-08-10 — Template catalog shipped: six built-in prebuilt decks in server/templates.ts (code, not a collection — no store behind it), served read-only and unauthenticated by GET /api/templates (+ /:id) and narrowed by two independently-ANDed filters, category (closed enum) and search (case-insensitive substring over title/description/category/tags). filterDeckTemplates() in server/schemas.ts is the one implementation of that narrowing, run by both the endpoint and the new gallery at src/pages/TemplatesPage.tsx, which fetches the catalog once and filters in the browser (ADR-0026) with matches marked by the new shared HighlightedText primitive (ADR-0019) — every searched field is on the card, tags included. Each card carries its slide-type row and a Use template button that copies the entry into a new editable deck and lands in the editor; reachable from the home hero and the empty state. Docs: api.md endpoint table + a Deck templates section, architecture.md, frontend.md.
