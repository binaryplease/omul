## Description

A deck carries a theme chosen from a built-in set. The theme drives colors, typography and slide backgrounds across the presenter, participant and join surfaces.

## Updates

- 2026-08-08 — Deck theme shipped: a closed built-in set of five themes (signal, pulse, ember, editorial, broadcast) derived from the product's design system, stored on the deck as an id only (theme field on Create/Presentation/StoredPresentation, defaulted to the house theme per ADR-0029). Appearance lives in src/components/DeckTheme.tsx as one catalog; <DeckThemeScope> writes it onto the existing --color-*/--font-* token vocabulary so colours, typeface and the slide-background wash repaint the presenter, participant, join and preview surfaces without per-surface work, while the viewer's own light/dark preference stays theirs. Chosen in the editor's Presentation settings panel and persisted through the ordinary owner-or-edit-token PATCH. Tests: server/theme.schemas.test.ts, server/theme.integration.test.ts, src/components/DeckTheme.test.ts (walks the schema enum through the catalog).
