## Description

A slide type where a participant orders a list of items; the tally aggregates the individual orderings into one ranking.

## Updates

- 2026-08-04 — Ranking slide type shipped end to end: "ranking" added to SlideTypeEnum/INTERACTIVE_SLIDE_TYPES, participants arrange the slide's items with per-item up/down controls (not drag — this surface is used on phones, where a drag competes with the page scroll, and buttons stay keyboard/screen-reader reachable) and submit the whole ordering as one vote. The ordering travels as a single VoteSchema.value — item ids best first, comma-separated — via the shared encodeRanking/decodeRanking pair in server/schemas.ts, so no new stored field was needed and one participant holds one ballot (re-submitting replaces it). getSlideResults aggregates Borda-style: an item placed p-th (0-indexed) earns itemCount - p points, ties break on average position then authored order. Results render on presenter, participant and preview surfaces; averageRank is an explicit null for an item nobody placed (ADR-0024). Covered by server/ranking.schemas.test.ts + server/ranking.integration.test.ts; verified in the browser end to end (vote -> aggregated ranking on the shared screen).
