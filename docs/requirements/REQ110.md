## Description

A slide can be marked skipped. Presenter navigation and audience pacing both step over it while the slide and any answers already on it remain.

## Notes

**Known limits and follow-up, from the pre-merge review (2026-10-25).** None blocks this record; each is recorded so it is not rediscovered.

- **The preview does not skip.** `/preview` shows a skipped slide like any other ("1 / 3" on a deck whose first slide is skipped). The presenter, the participants and the PDF behave as specified; follow-up for the side view.
- **A skipped first slide is in the DOM for a moment.** On an audience-paced deck whose first slide is skipped, the participant's screen holds that slide's text for about 3–5ms before it moves to the first unskipped slide — shorter than a frame, and not seen to be painted.
