## Description

A presentation can require each submitted question to be approved before it becomes visible or upvotable; unapproved questions are reachable only by an editor.

## Updates

- 2026-10-01 — Shipped: an opt-in deck setting qaApprovalRequired (default off; set via POST /qa/settings and the presenter's Q&A panel) stores each new question with approved: false (stored questions default to approved). Until an editor approves it via POST /qa/:questionId/approve (owner/edit token, one-way, emits qa.updated), it is left out of every non-editor list (its asker's included), cannot be upvoted (same 400 as a foreign id), and is never a duplicate-fold target. Switching the setting off releases nothing still waiting.
