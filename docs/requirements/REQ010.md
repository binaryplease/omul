## Description

A question slide carries the visualization its results are drawn in — bar, donut, pie, dots — as slide state, so the same stored answers render differently without being rewritten.

## Updates

- 2026-07-28 — Result visualization is now a per-slide setting with four styles: mcDisplayStyle extended from bars/dots to bars/donut/pie/dots. Pie and donut share one stroked-circle renderer in Results.tsx (a pie is a donut whose ring reaches the centre); the editor picks between them with one shared descriptor (MC_DISPLAY_STYLE_OPTIONS). Existing slides default to bars, unchanged.
