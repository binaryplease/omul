## Description

A deck can mint a link granting read-only access to its results with no account. The link is revocable and carries no edit authority.

## Updates

- 2026-08-10 — Shareable results link shipped: POST/DELETE/GET /api/presentations/:id/results-link (owner or edit token) mint, revoke and report one per-deck token, stored as a SHA-256 hash beside the edit token's and presented on the two results endpoints as X-Omul-Results-Token. The link lifts the deck's reveal mode and nothing else — tallies under private and unrevealed on-click, but no mutation, no XLSX or preview, no running question's answer key, no presenter notes and no Form per-participant rows — through the single tallyVisibleToCaller() gate in server/schemas.ts. Revocation clears the hash and is refused rather than demoted to the public read (401), so a holder learns their link is gone; re-minting retires the previous link by the same act. Client: /results/:id read-only page fed by api.getSharedResults, token carried in the URL fragment, plus a mint/copy/revoke dialog beside the presenter's export and reset controls. Both decisions written up in docs/api.md.
