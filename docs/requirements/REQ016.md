## Description

A question slide can collect answers without publishing a tally, and publish it only when the presenter reveals it.

## Updates

- 2026-08-08 — On-click mode now genuinely withholds: aggregateSlideResults() returns a { type, withheld: true } marker to any caller that cannot edit the deck until the presenter reveals that slide, so the tally no longer travels to the room and is merely hidden client-side. The reveal control (REQ102) and its hide are unchanged; api.getResults() reads the marker back as null in one place. Covered end to end over HTTP, including that ending the deck is not a reveal.
