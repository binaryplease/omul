## Description

As a presenter opening the home page, I want each card under "Your Presentations" to show the presentation's title in readable form and its code, slide count and date on one tidy row, so that I can tell my decks apart without opening them.

## Notes

**What happens today (defect, unreproduced in a browser here; reported with a screenshot at a two-column width).** The card at `src/pages/HomePage.tsx:318` is one flex row: a slide-count square (`:323-326`), the text block (`flex-1 min-w-0`, `:328`), then five icon buttons — share, move to workspace, export, duplicate, delete (`:347-422`). Each button is `p-2` around an 18px icon and is only `opacity-0` until hover (`:350`, `:373`, `:391`, `:402`, `:414`), so all five keep their width while invisible: roughly 170px of buttons plus four more 16px gaps. Inside the `md:grid-cols-2 xl:grid-cols-3` grid (`:315`) that leaves the text block a few dozen pixels, so the `truncate` title (`:330`) shows as its first letter and an ellipsis ("J…", "D…"), and the metadata row (`:333-342`) wraps "1 slide" over two lines while code and date stay on one. The slide count also appears twice, in the square and in the metadata row.

**Desired outcome.** Each card on the home page shows enough of the presentation's title to identify it and keeps code, slide count and date each on a single line at every grid width the list uses.

**Done when.** At the `md` two-column and `xl` three-column breakpoints, a presentation titled with at least 30 characters shows at least its first 20 characters on the card without hover, no metadata item wraps, and all five actions stay reachable; `mise run check` and `mise run test`, as `AGENTS.md` declares them, apply unchanged.

**Out of scope.** The set of card actions and what each one does stay as they are; only their presentation on the card is in question. Sorting, filtering or searching the list is not part of this requirement.

**Note.** The "Shared with You" section (`src/pages/HomePage.tsx:441-470`) copies the same square, title and metadata markup but carries no action buttons, so its title is not squeezed the same way today; if the own-deck card changes shape, that list will look different from it until a later change brings the two together.
