## Description

A slide can embed an externally hosted Google Slides deck and page through it within the presentation flow.

## Updates

- 2026-08-11 — Shipped as part of the 'embed' content slide type. slideEmbedFor() normalises a Google Slides link to docs.google.com/presentation/d/<id>/embed — every share tail (/edit, /preview, /htmlpresent) and the published /d/e/<id>/pub form, whose different id is kept as such; the /edit tail never survives so a room is never shown an editor, and a publish link's start/loop/delayms autoplay is dropped. Same one editor field, note, rail gist and sandboxed frame as the other two providers. Paging is the Google viewer's own control inside the frame; the deck stays in Drive. Tests: server/embed.schemas.test.ts, server/embed.integration.test.ts.
