## Description

A check over a deck reports its accessibility risks per slide — contrast, text size, structure — as findings an editor can act on.

## Notes

### Slices

- [x] **REQ132/1-deck-check** — a pure check over a deck returns its accessibility findings per slide (contrast, text size, structure), each naming the field that clears it. Client module and tests only; no UI. Built by NST11836-deck-accessibility-check.
- [x] **REQ132/2-editor-findings** — the deck editor runs slice 1's check and shows its findings per slide, each one taking the editor to the slide and field it names. Closes REQ132. Built by NST11841-editor-accessibility-check.

### The check (slice 1)

- **Where:** `src/components/DeckAccessibility.ts`. `deckAccessibilityFindings(deck, slides)` returns every slide's findings in deck order, and `slideAccessibilityFindings(deck, slide, index)` returns one slide's. Each finding is plain data: `slideId`, `slideIndex`, `category` (`contrast` / `text-size` / `structure`), `risk`, a `message` in the organizer's words, the `field` to change (`{ scope: "slide", name }` or `{ scope: "deck", name: "theme" | "themeBrand" }`), and for contrast a `contrast` measure (`ratio`, `required`, `schemes`). A slide with nothing to report gives `[]`. Every `SlideTypeEnum` type is covered.
- **contrast (`low-contrast`):** checks `--color-text` against what it sits on, in both colour schemes, using the colours the slide renders with: the deck theme's tokens with `slideAppearanceStyle` on top. A content slide or a leaderboard with a background image is judged against the worst backdrop its scrim can produce (`SCRIM_TONES[…].against`), because both draw their words straight onto it. A question slide is judged against its canvas: its heading wears the scrim's paired colour (`slide-title-overlay`), which `slideScrimFor` already holds to AA, and its answers sit on cards. WCAG 2.2 AA thresholds: 4.5:1 when the slide draws body-size words (every non-content slide, the join slide, any body) or a Small heading, and 3:1 when its heading is all it carries. The `field` is the slide's text colour, then its canvas, then its picture, then the deck's brand or theme.
- **text size (`small-text`):** a heading or body set at the `small` step, counting the default heading the join slide and the leaderboard draw when none is written.
- **structure (`missing-alt`, `missing-heading`):** a `mediaUrl` drawn as an image (every question's illustration, a pin slide's canvas, a text or image slide's picture, but not a video or embed URL) whose `mediaAlt` is blank; a blank `question` on every type but `instruction` and `leaderboard`, which draw a default heading.
- **Not checked yet:** the muted and dim text steps, link text, and the theme's slide wash. The render-time floors in `DeckTheme.tsx` / `SlideAppearance.tsx` are unchanged.

### The editor findings (slice 2)

- **Where:** `src/components/AccessibilityFindings.tsx`, wired by `src/pages/CreatePage.tsx`, which re-runs `deckAccessibilityFindings` on every edit to a slide or the theme. `<AccessibilityFindingsStrip/>` sits under the canvas beside the notes and comment strips and lists the slide's findings, each `message` with one control named for its field. A slide with none says so in one line, along with how many the other slides hold. Each rail thumbnail (`SlideThumbnail`) carries its slide's count.
- **Going to a field:** `accessibilityFindingDestination()` is pure. A slide field selects the finding's slide. A deck field (`theme` / `themeBrand`) opens the presentation settings and keeps the finding's slide on the canvas. The heading also returns the canvas to its question view. Each control that edits a named field carries `accessibilityFieldMarker()`: the Style group's text size, background, text and background-image controls, the alt text on a question's illustration, a text, image or pin slide, the canvas heading, the deck's theme picker and the brand's Text colour. `revealAccessibilityField()` opens the closed disclosure the field rests in, scrolls to it and focuses it.
- **One editor gap closed:** a text slide's picture had no alt text field, though the check asks for one. It now has one, under its image URL.
- Advisory only: Save, Present and Publish read none of it.
