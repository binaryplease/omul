## Description

A guess slide carries a minimum and a maximum. A submission outside the range is refused rather than clamped, because an adjusted number is an answer the participant never gave.

## Updates

- 2026-08-05 — Value range shipped as guessRange {min, max, step} on SlideSchema (GuessRangeSchema, defaulting to 0-100 in steps of 1 so a deck authored before the type existed re-parses forward without migration, ADR-0029). Range and resolution are one object rather than three loose fields because neither is usable alone — a range without a step does not say which numbers inside it may be picked — and guessRangeFor() resolves it once for the four surfaces that need it (vote validator, participant input, aggregation, plot) per ADR-0026. Whole numbers only, with the reasoning recorded in schemas.ts: a fractional step makes "is this guess on the grid?" undecidable without an epsilon, and decimal resolution is re-expressed by naming the unit (cents, tenths) rather than lost. decodeGuess rejects a guess outside the range with 400 at the boundary rather than clamping it — on this slide type the number is the whole answer, so a clamped one is an estimate the participant never made — and a stored guess stops counting if the organizer later narrows the range, rather than plotting off the end of the axis. isUsableGuessRange() fails closed on a frame that is not a frame (max <= min, or a step wider than the span): no submission is accepted at all. The editor states the frame in three number fields with a live "11 selectable values: 0, 2, 4, … up to 20" hint, CreatePage refuses to save an unusable one, and the participant surface prints the allowed range above the input rather than leaving it to be discovered by a rejection. Tests: server/guess.schemas.test.ts + server/guess.integration.test.ts (both endpoints guessable, out-of-range rejected with 400, a narrowed range drops the stored guess). Verified in the browser on a 0-20 slide: 24 was refused with "That number is outside the allowed range" and the + stepper clamped it back to 20.
