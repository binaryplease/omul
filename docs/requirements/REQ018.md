## Description

The reveal mode of REQ015–REQ017 can be set once for a deck and applied to every question slide in it, in one operation.

## Updates

- 2026-08-08 — One operation sets the deck's reveal mode and applies it to every question slide: POST /api/presentations/:id/results-visibility (owner or edit token) writes the deck default and clears every question slide's override via the shared withInheritedResultsVisibility(), broadcasting presentation.results-visibility so live phones follow without a reload. The editor composes the identical function on its local document, behind an Apply-to-every-question-slide button that names how many slides it changes and states that it loosens as readily as it tightens (ADR-0025/ADR-0031). Content slides untouched.
