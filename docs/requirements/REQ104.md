## Description

Synthetic answers can be generated against a slide to exercise its visualization, and cleared again without touching answers a real participant gave.

## Updates

- 2026-08-06 — Test votes shipped: server/preview.ts generates deterministic synthetic responses for every slide type that collects them — choice (single and capped multi-select), word cloud, open text (with REQ025 duplicate folding into upvotes), single- and multi-statement scales with skips, ranking (including partial ballots), 2x2 grid with skips, 100 Points ballots that spend exactly the budget, guess-the-number on the authored step grid, and quiz in both answer modes inside the question window; a leaderboard fills from the quiz votes beside it. Rows are built with the same encoders a phone uses and parsed through StoredVoteSchema, so a test vote is the shape a real one is and passes the same decoders. Isolation is structural rather than a filter: the generator has no store, the aggregation only reads, and the preview deck is never persisted — covered by preview.integration.test.ts (after 600 test votes the deck is still an untouched draft with no votes, no standings and no scorecards) and by PreviewPage.test.ts, which proves the client transport makes no network call at all.
