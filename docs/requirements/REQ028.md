## Description

A slide type rating one or more statements on a shared numeric scale.

## Updates

- 2026-08-10 — Bookkeeping only — no code change. Traced through all of server/schemas.ts, submitVote's per-statement dedup branch, aggregateSlideResults' scale case, preview.ts's scaleVotes, results-export's describeAnswer/aggregateRowsFor, and on the client through SlideEditor, SlidePreview, SlideThumbnail, ParticipantSlideView and ScaleResults. Found no gap that REQ029-REQ032 do not already cover, so REQ028 closes as satisfied by shipped code.
