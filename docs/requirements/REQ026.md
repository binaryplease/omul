## Description

Word cloud and open-ended slides accept repeated submissions from the same participant, bounded by the slide's cap (REQ022).

## Notes

**Known limits and follow-up, from the pre-merge review (2026-10-25).** None blocks this record; each is recorded so it is not rediscovered.

- **After a reload the participant's count and live results are gone.** On a word cloud or open-ended slide with a cap, "2 sent · 1 remaining" and the live results disappear on reload, leaving only the field and Send; a multiple-choice slide loses its selection and live results the same way. Confirmed in the pre-merge browser run. The count and the answered state live only in the participant view's React state (`voted`, `submitCount` in `src/components/ParticipantSlideView.tsx`), set by the submit handlers and read back from nothing; only quiz and leaderboard slides fetch their own standing (`transport.scorecard()`). From main; follow-up.
