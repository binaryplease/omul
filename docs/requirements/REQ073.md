## Description

The join instruction bar on the presenter surface can be shown or hidden without changing whether the deck accepts joins.

## Updates

- 2026-10-01 — Shipped as a per-deck showJoinBar setting (server/schemas.ts: stored and response default true, so a deck stored without it reads as shown; writable only through UpdatePresentationSchema on PATCH /api/presentations/:id under its owner-or-edit-token authorization). updatePresentation broadcasts presentation.join-bar so every presenter screen of the deck follows; the session store applies it and PresenterPage draws a toggle chip beside the bar (disabled with its reason for a viewer who cannot edit) and hides both the xl inline ShareCluster and the md..lg row while it is off. The join code, /join/:code, status and submissions never read the field. Covered by server/join-bar.integration.test.ts: default for a stored deck without the field, authorized hide/show persisting, editor saves leaving it alone, the socket frame, refusal for an anonymous caller and another deck's token, no other route writing it, and join lookup plus voting unchanged while hidden. Documented in docs/api.md.
