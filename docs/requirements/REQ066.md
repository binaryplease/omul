## Description

A slide can embed an externally hosted PowerPoint deck and page through it within the presentation flow.

## Updates

- 2026-08-11 — Shipped as the 'embed' content slide type. slideEmbedFor() in server/schemas.ts normalises a PowerPoint link to Microsoft's own viewer: a .ppt/.pptx/.pps/.ppsx/.pot/.potx URL on any web host becomes a view.officeapps.live.com embed, a OneDrive share becomes onedrive.live.com/embed (em=2, sharing parameters kept), a SharePoint /:p:/ share gains action=embedview, and an existing Office viewer URL is re-pointed at its own src. Editor field + provider note (SlideEditor), rail gist (SlideThumbnail), and one sandboxed frame drawn by ContentSlideView for the preview pane, the shared screen and the phones. Paging is the viewer's own control inside the frame; the file stays externally hosted and nothing is uploaded, converted or proxied. Tests: server/embed.schemas.test.ts, server/embed.integration.test.ts.
