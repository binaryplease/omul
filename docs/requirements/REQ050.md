## Description

A grid slide can allow a participant to skip an item. The skip is stored as its own outcome and excluded from the item's mean coordinate.

## Updates

- 2026-08-05 — Slide.gridAllowSkip (default false) mirrors scaleAllowSkip: participants get a 'Not assessable' control per item, riding the existing VoteSchema.skip flag. The server refuses a skip on a slide that did not enable it, a skipped item is counted (items[].skipped) and never averaged, and the participant may still place an item after skipping it.
