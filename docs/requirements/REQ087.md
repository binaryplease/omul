## Description

A slide carries its own layout — element placement, background, colors — layered over the theme's defaults.

## Updates

- 2026-08-11 — Per-slide appearance shipped as one layer over the deck theme: SlideSchema gains layout / backgroundColor / textColor / chartColor beside the existing backgroundImage, all defaulted to an 'unauthored means the theme's' value (ADR-0029). slideAppearanceFor() is the single read site and the guard — unknown layout, non-colour string and unloadable URL all resolve to the theme's. On the client, <SlideAppearanceScope/> (src/components/SlideAppearance.tsx) writes the resolved values onto the existing --color-* vocabulary the way <DeckThemeScope/> does one layer down, and SLIDE_PLACEMENT_CLASSES is the one catalog of what a placement means in layout terms. Honoured on every surface a slide is drawn on: presenter, participant, both preview panes, the editor's preview pane and filmstrip, and the shared results page. Authored in a new Appearance section of the slide editor, built on a new shared ColorField primitive (also now used by the deck brand fields). Guarded by scripts/guard-frontend-conventions.ts (REQ087 raw slide appearance field).
- 2026-08-11 — Review fix (NST8763). Correcting the entry above: 'honoured on every surface a slide is drawn on ... and the shared results page' overstated two surfaces. SharedResultsPage applies SlideAppearanceScope — so REQ019's text and chart colours do reach it — but renders no SlideBackground, so a slide's background colour and image are not drawn there; the editor's filmstrip carries the background but deliberately not the text or chart colours. Both are now stated in docs/frontend.md. Also: slideOverridesAppearance() is dropped (finding 2 — it had no production consumer and its docstring named two callers that do not exist), and the frontend guard is tightened (finding 3) — the unnecessary store/editorDocument.ts allowlist entry is removed and the pattern now matches the identifier by suffix, so activeSlide./audienceSlide. no longer slip past.
