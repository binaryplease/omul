## Description

Whether the submitted questions and their upvotes are visible to participants, or only to the presenter, is deck state enforced on the read path.

## Updates

- 2026-08-06 — qaVisibility on the presentation schema, presenter | everyone, defaulting to the withholding value — publishing a room's unfiltered questions is the failure an organizer cannot take back, and the control sits beside the switch that opens the floor (imports tighten to presenter too). Who reads what is decided server-side per request from the caller's own credentials, never filtered on a client: whoever can edit the deck reads the whole list always (layer off included), everyone else reads the room's only while the layer is on and published, and otherwise their own submissions alone. The qa.updated broadcast is payload-free for the same reason — the WS role is self-declared — so every surface re-fetches GET /qa where the edit token is proven. Participant ids never reach a client.
