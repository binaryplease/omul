## Description

The answers collected under a deck can be cleared, returning it to its pre-session state without deleting the deck or its slides.

## Updates

- 2026-08-06 — Results reset shipped on the results surface: the presenter's Reset control is now offered at every deck status (disabled with its reason for a non-owner, ADR-0025) and confirmed with what it costs before POST /presentations/:id/reset clears every vote, response upvote and Q&A question and returns the deck to draft. Integration tests cover the 401 refusal, the cleared tally and that a re-run's results never mix with the run before it. Retaining old sessions remains REQ100.
