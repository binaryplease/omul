## Description

A grid slide carries the endpoints of both axes, readable either as numeric bounds or as qualitative labels.

## Updates

- 2026-08-05 — Axis endpoints are authored numbers (min/max, default 0-10) with optional pole labels; an empty label means 'read this end as its number', so one axis serves a low/high pair and a 0-10 range alike (gridEndLabel is the single read site). decodeGridPoint bounds every placement to its own axis and rejects non-integer or off-grid points instead of clamping; CreatePage requires low < high.
